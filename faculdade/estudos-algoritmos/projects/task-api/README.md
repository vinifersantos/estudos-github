# Task API

Projeto de uma API de tarefas com TypeScript e PostgreSQL.

Escopo inicial:

- Criar, listar, atualizar e concluir tarefas.
- Validar entradas e devolver erros amigáveis.
- Usar queries parametrizadas.
- Modelar `tasks` com `id`, `title`, `completed` e `created_at`.

As credenciais locais devem ficar apenas em `.env`; nunca publique segredos.
